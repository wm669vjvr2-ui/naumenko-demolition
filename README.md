# НК/ДМ — сайт демонтажных работ

Анимированный промо-сайт компании Науменко и интерактивный прототип CRM-воронки в стилистике Битрикс24.

## Что внутри

- `/` — тёмный индустриальный лендинг с анимацией демонтажа, услугами, объектами, этапами и формой заявки;
- `/crm` — кликабельный прототип CRM: канбан, поиск, создание сделки, карточка клиента и перевод по стадиям;
- адаптивная версия для телефона и поддержка `prefers-reduced-motion`.

## Запуск

```bash
pnpm install
pnpm run dev
```

Проверка production-сборки:

```bash
pnpm run build
```

Контакты, регион, цены и реальные фотографии пока используются как демонстрационный контент и заменяются перед боевым запуском.
